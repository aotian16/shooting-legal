支持

没有 Apple Watch 也能用吗？

可以。手机端有独立的记分员模式，可以直接记录出手、区域和备注。

数据存在哪里？

数据保存在你的 iPhone 和 Apple Watch 本地，不会上传到开发者服务器。你可以在「数据管理」里导出 JSON 备份或 CSV。

换手机或重装 App 后怎么恢复？

先在旧设备导出 JSON 备份，再在新设备的「数据管理」里导入。

Support

Can I use the App without an Apple Watch?

Yes. The iPhone app includes a standalone scorekeeper for shots, zones, and notes.

Where is my data stored?

Data stays on your iPhone and Apple Watch. It is not uploaded to a developer server. Use Data to export a JSON backup or CSV file.

How do I restore after changing phones or reinstalling?

Export a JSON backup from the old device, then import it from Data on the new device.

サポート

Apple Watch がなくても使えますか？

はい。iPhone 版にはシュート、位置、メモを記録できる単体のスコアキーパーがあります。

データはどこに保存されますか？

データは iPhone と Apple Watch 内に保存され、開発者のサーバーには送信されません。「データ」から JSON バックアップまたは CSV を書き出せます。

機種変更や再インストール後に復元するには？

以前の端末で JSON バックアップを書き出し、新しい端末の「データ」から読み込んでください。
